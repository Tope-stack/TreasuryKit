# TreasuryKit

Treasury tooling for African businesses operating across borders. Phase 1 focuses on multi-bank statement reconciliation. See [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Run locally

Prerequisites: .NET SDK 10.0.400+, Docker.

```bash
docker compose up -d                                   # PostgreSQL on localhost:5433
dotnet run --project src/Host/TreasuryKit.Api          # http://localhost:5080 (applies migrations)
dotnet run --project src/Host/TreasuryKit.Worker       # outbox dispatcher
```

- Health: `GET /health`
- API reference (Development): http://localhost:5080/scalar
- Get a token (Development only):

```bash
curl -s -X POST localhost:5080/dev/tenants -H 'content-type: application/json' -d '{"name":"Acme Ltd"}'
curl -s -X POST localhost:5080/dev/token -H 'content-type: application/json' \
  -d '{"tenantId":"<id>","userId":"alice","roles":["Preparer"]}'
```

### Import a statement (Development)

```bash
# with an Admin token in $TOKEN; mappingProfileId 5e3d6a10-…-00000000000a is the seeded "Generic layout A"
curl -s -X POST localhost:5080/api/core/accounts -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"bankCode":"058","bankName":"Demo Bank","accountNumber":"0123456789","currency":"NGN","mappingProfileId":"5e3d6a10-0000-4000-8000-00000000000a"}'
curl -s -X POST localhost:5080/api/core/accounts/<accountId>/statements -H "Authorization: Bearer $TOKEN" \
  -F file=@tests/TestData/statements/layout-a/clean.csv     # 202 { importId }; the Worker processes it
curl -s localhost:5080/api/core/imports/<importId> -H "Authorization: Bearer $TOKEN"
```

Supported formats: CSV/XLSX (through the account's mapping profile), MT940 and CAMT.053 (self-describing; the account number in the file must match). Sample statements are in `tests/TestData/statements` (generated by `tools/StatementGen`).

### Reconcile (Development)

```bash
curl -s -X POST localhost:5080/api/core/expected-transactions/import -H "Authorization: Bearer $TOKEN" \
  -F file=@tests/TestData/recon/expected.csv          # payables/receivables, idempotent by externalId
curl -s -X POST localhost:5080/api/core/accounts/<accountId>/statements -H "Authorization: Bearer $TOKEN" \
  -F file=@tests/TestData/recon/statement.csv         # the import triggers a reconciliation run automatically
curl -s "localhost:5080/api/recon/runs?accountId=<accountId>" -H "Authorization: Bearer $TOKEN"
curl -s "localhost:5080/api/recon/matches?accountId=<accountId>" -H "Authorization: Bearer $TOKEN"
curl -s "localhost:5080/api/recon/exceptions?accountId=<accountId>&status=Open" -H "Authorization: Bearer $TOKEN"
```

The account number must be `0123456789` for the sample data. Regenerate it with `dotnet run --project tools/StatementGen -- --recon --out tests/TestData/recon`.
